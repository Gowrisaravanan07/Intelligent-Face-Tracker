Pipeline Architecture & AI Workflow

This system is architected for real-time video surveillance visitor counting using a multi-stage Deep Learning pipeline:

  1. Video Stream Capture: Threaded OpenCV capture with auto-reconnection for live RTSP streams and file playback.
  2. Face Detection & Frame Skipping: High-speed InsightFace / RetinaFace / YOLO face detector executed every (frame_skip + 1) frames.
  3. Kalman Motion Tracker: IoU and velocity motion prediction extrapolating bounding boxes during skipped frames to ensure 0% tracking drop.
  4. ArcFace 512-D Embedding Extraction: Generates normalized facial vectors matched against SQLite in-memory gallery using matrix cosine similarity.
  5. Idempotent Auto-Registration & Logging: Automatically assigns unique identifiers (VISITOR_0001) and writes exactly 1 Entry event and 1 Exit event per appearance session.

Compute Load & Optimization Analysis

  • • Frame Skip = 0 (Full Detection): ~6-10 FPS CPU, 85% CPU load.
  • • Frame Skip = 3 (Recommended): ~22-28 FPS CPU, 45-60% CPU load (60% compute savings).
  • • Memory Footprint: ~350-450 MB RSS RAM.
